The goal of this assignment is to implement several image comparison metrics and identify their uses and limitations. The formulas are in [Image Metrics](https://ufl.instructure.com/courses/576415/files/108439563). The [Blender Introduction](https://ufl.instructure.com/courses/576415/files/108439540) slides from class get Blender installed for the simulated labs ahead; nothing in this assignment uses it.

## Tasks

1. Put your group's Lab 0 pictures at the repository root: the original `mountains.png`, your posterized `quantized.png`, `controlnet.png` and `favorite.png`. Lab 0 was done before this workspace existed, so they are not in any repository: copy them from wherever your group kept them, rename them to these names if needed without changing the images, and commit them. `quantized.png` must be exactly the correct Lab 0 answer: every channel of `mountains.png` quantized at thresholds 50, 100 and 150, values below 50 to 50, 50 to 99 to 100, 100 to 149 to 150, and 150 and above to 200, so every value lands on one of the four levels. If your Lab 0 result differs, for example other levels or values left unquantized, fix it first and use the corrected image; metrics on any other quantized image are not accepted.

2. **Part 1 (50 points):** implement MSE, MAE and PSNR yourself, without the built-in MATLAB or Python metric functions. Use them to compare the original `mountains.png` with each of your Lab 0 results, and write out next to the values the equation you used for each metric. Briefly discuss your findings. Can you use any of these metrics to tell a posterized image from a noisy image? Why or why not?

3. **Part 2 (50 points):** implement one image perturbation of your choice: warp, translation, noise, mosaic, filters, and so on. You may use pre-made functions for the perturbation. Save the result as `perturbed.png` and compare it with the original using MSE. Briefly discuss why the MSE is higher or lower than in Part 1. What are some of the limitations of MSE? What kind of information would you need for a more robust image comparison metric?

4. **Bonus (9 points, optional):** implement one other image comparison metric, such as SSIM from Image Metrics; pre-made functions are allowed here. Use it to compare the original with your Lab 0 results and with your Part 2 result, and write out the equation it computes. Discuss how the metric works. Would it let you tell a posterized image from a noisy one?

5. **Bonus (1 point, optional):** leave a comment with your Canvas submission on what part of this assignment could be improved.

The starter script `metrics.py` loads the images, resizes any that differ from the original's size, writes `perturbed.png` and prints a table of the three metrics once you fill in its four stubs: `mse`, `mae` and `psnr` for Part 1 and `perturb` for Part 2. A noise perturbation also gives you a noisy image to set beside the posterized one.
